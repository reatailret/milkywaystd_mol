# Приложение "Заметки"

Простое и удобное приложение для создания и управления заметками, построенное на фреймворке $mol с использованием CRUS (Convergent Realtime Unbreakable Secure Database).

## Возможности

- ✏️ **Создание заметок** - легко создавайте новые заметки с заголовком и текстом
- 🔍 **Поиск** - быстрый поиск по заголовкам и содержимому заметок
- 📅 **Даты** - автоматическое отслеживание даты создания и обновления
- 🗑️ **Удаление** - удаление ненужных заметок
- 💾 **Автосохранение** - все изменения сохраняются автоматически
- ✈️ **Оффлайн-работа** - полная работоспособность без интернета
- 🔄 **Синхронизация** - автоматическая синхронизация между устройствами

## Модель данных

### $mws_app_notes_note
Сущность заметки с полями:
- **Title** - заголовок заметки (унаследовано от `$giper_baza_entity`)
- **Content** - текст заметки (`$giper_baza_text`)
- **CreatedAt** - дата создания (`$giper_baza_atom_time`)
- **UpdatedAt** - дата последнего обновления (`$giper_baza_atom_time`)

### $mws_app_notes_person
Корневая сущность пользователя:
- **Note** - список заметок (`$giper_baza_list_link_to`)

## Запуск приложения

### Локальная разработка

Из корня MAM проекта:

```bash
# Запустить dev-сервер
npm start mws/app/notes
```

Приложение будет доступно по адресу: `http://localhost:9080/mws/app/notes/`

### Сборка для продакшена

```bash
# Собрать приложение
npm run build mws/app/notes
```

Скомпилированные файлы появятся в `mws/app/notes/-/`

## Использование

1. **Создание заметки**: Нажмите кнопку "Создать заметку"
2. **Редактирование**: Введите заголовок и текст заметки в соответствующие поля
3. **Поиск**: Используйте поле поиска в верхней части для фильтрации заметок
4. **Удаление**: Нажмите кнопку "Удалить" в карточке заметки

## Технические детали

- **Фреймворк**: $mol
- **База данных**: CRUS (HYOO)
- **Хранение**: IndexedDB (локально)
- **Реактивность**: Автоматическая через $mol_mem
- **Язык**: TypeScript

## Особенности реализации

- Заметки автоматически сортируются по дате обновления (новые сверху)
- Поиск работает в реальном времени по заголовку и содержимому
- Все изменения немедленно сохраняются в локальную базу данных
- Полная поддержка оффлайн-режима
- Готовность к реалтайм-синхронизации между устройствами
